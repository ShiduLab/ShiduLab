## La firma è nei progetti

La vetrina elenca i progetti; le loro fotografie e schermate originali appartengono ai **README dei singoli repository**. Nessuna fotografia stock.

Alcuni repository distribuiscono applicazioni o codice; altri documentano prototipi e progetti online. Gli archivi audio/video personali e il codice del motore privato di MyJong non vengono pubblicati come parte di questa vetrina.
